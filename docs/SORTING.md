# Sorting Rules

Sorting rules apply only to the main listing pages.

Home page preview sections may use their own ordering.

## Chronological: Old → New

Sort these sections by their relevant date in ascending chronological order:

- Projects
- Experience
- Education
- Certificates
- Achievements
- Competitions

Recommended date fields:

| Section | Sorting field |
| --- | --- |
| Projects | Relevant project date / start date |
| Experience | Start date |
| Education | Start date |
| Certificates | Issue or completion date |
| Achievements | Achievement date |
| Competitions | Competition date |

## Alphabetical: A → Z

Sort these sections by name:

- Skills
- Technologies

Use a case-insensitive alphabetical comparison where appropriate.

## Important Scope

These rules are intended for main pages only:

```text
/projects
/skills
/experience
/education
/certificates
/achievements
/competitions
/technologies
```

Home page sections are not required to use the same sorting rules because they may prioritize featured, recent, or manually selected content.
