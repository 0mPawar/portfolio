# Om Pawar | Portfolio Website

A personal portfolio website built to showcase projects, skills, technologies, experience, education, certificates, achievements, competitions, and other professional information.

The website uses a structured, data-driven approach where most portfolio content is managed through JSON files.

## 🚀 Live Demo

[View Portfolio](https://0mpawar.github.io/portfolio/)

## ✨ Features

- Responsive portfolio design
- Light and dark mode support
- Projects showcase with detailed project pages
- Skills and technologies sections
- Professional experience and education
- Certificates with preview and detailed information
- Achievements and competitions sections
- Related data linking between portfolio entities
- GitHub contribution calendar
- Contact information and social links
- Portfolio status alerts
- Data-driven content using JSON files
- Reusable UI components

## 🖥️ Local Development

### Clone the repository

```bash
git clone https://github.com/0mPawar/portfolio.git
```

### Navigate to the project

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

## 📦 Build for Production

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 Deployment

The portfolio is designed to be deployed using GitHub Pages.

Example:

```text
Repository:
0mPawar/portfolio

Website:
https://0mpawar.github.io/portfolio/
```
